# BabyCare — Aanchal Mother & Baby Care

Pregnancy-to-18-months home-care platform for the Chandigarh Tricity ("Aanchal" is a working name).

## Live preview (GitHub Pages)
- Overview: https://mycodeclub.github.io/BabyCare/templates/
- Landing page: https://mycodeclub.github.io/BabyCare/templates/landing/
- Admin dashboard: https://mycodeclub.github.io/BabyCare/templates/admin/dashboard.html
- Customer booking: https://mycodeclub.github.io/BabyCare/templates/user/book.html
- Project plan PDF: https://mycodeclub.github.io/BabyCare/docs/Aanchal_Project_Plan.pdf

## Contents
| Folder | What |
|---|---|
| `docs/` | Project plan PDF (23 pages), executive summary, HTML source of the report |
| `templates/` | Static HTML/CSS/Bootstrap 5 templates: landing, admin panel (7 pages), customer portal (3 pages) |

Tech stack for the build: ASP.NET Core MVC + Web API, EF Core, SQL Server, React Native (Android).
All names, partners and figures in the templates are sample data. Prices and projections are planning assumptions.
